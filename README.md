# タスク管理アプリ

タスクを登録し、期限・優先度・担当者・進捗を一覧で確認するFlaskアプリです。登録内容はSQLiteに保存されます。完了した作業へのGemini AIコメント機能も利用できます。

トップ画面には総タスク数と、未着手・進行中・完了・保留のステータス別件数を表示します。検索中もダッシュボードは全タスクを集計します。

## 起動方法

```bash
pip install Flask google-genai
python app.py
```

ブラウザーで `http://localhost:5000` を開きます。タスク管理機能はAPIキーなしで利用できます。AIコメントを利用する場合は `GEMINI_API_KEY` を環境変数に設定してください。

## タスク登録項目

- タスク名
- タスク詳細
- 期限日
- 優先度（高・中・低）
- 担当者
- ステータス（未着手・進行中・保留・完了）

一覧にはタスク名、担当者、優先度、ステータス、期限日、作成日を表示します。タスク名を選択すると詳細画面を開き、完了日時と更新日時を確認できます。編集ボタンからタスク情報を変更でき、更新日時は編集のたびに更新されます。完了へ変更すると完了日時を記録し、未完了へ戻すと完了日時を解除します。削除ボタンを押すと確認ダイアログが表示され、確認後に削除して一覧へ戻ります。

一覧上部の検索フォームで、タスク名・担当者の部分一致、ステータス・優先度、期限日の開始・終了範囲を組み合わせて検索できます。

同じフォームで作成日・更新日・期限日・優先度を昇順または降順に並べ替えられます。優先度の昇順は高・中・低の順です。

タスク詳細画面から作業報告・引継ぎ内容・課題・備忘録などのコメントを投稿できます。コメントは投稿日時とともに新しい順で表示され、タスク削除時に関連コメントも削除されます。

タスク・コメント・日時情報はワークスペース内の `instance/tasks.sqlite3` に保存され、アプリを再起動しても保持されます。既存データベースには不足する列を追加して引き継ぎます。このローカルDBはGit管理対象外のため、長期保管や障害復旧が必要な場合はDBファイルを別途バックアップしてください。
